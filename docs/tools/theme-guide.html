Palette axes

Authoring knobs. Every reference colour token is derived from these via oklch() + calc() — override an axis to retune a whole family.

Reference ramps

10-tint scales for each family. Lightness ladder is non-negotiable across families; chroma curves bell around step -50.

Role · Surface

Layered surfaces from canvas (top-most page) to overlay. Use these instead of reference colours so a palette change automatically updates them.

Role · Text

Text colour roles. Default + heading for content, muted for secondary, link for navigation, inverse for dark surfaces.

Role · Border

Border weights from subtle (table dividers) through strong (focus / emphasis).

Role · Interactive

Primary/secondary action surfaces with hover and on-content variants. The "primary" colour is what most JUI components consume.

Role · Feedback / Focus / Disabled / Selection

Status colours used in notifications, validation, and interaction states.

Typography

Font families, size scale, weights, line heights. Sizes are in rem; the rendered px value depends on the html root font-size (16px by default).

Spacing scale

Use these for padding, margin, gap. Values are in rem so they scale with the user's font-size preference.

Radii

Visual decoration; intentionally in px so corner sizes stay proportionate at any text scale.

Elevation

Box-shadow ladder. Higher elevation = greater visual lift away from the page surface.

Motion

Animation duration tokens and easing curves. Use the standard ease for most transitions; emphasis for entrance / exit.

Components · Button

Button structural + variant tokens. Live previews use the resolved token values; they are visual replicas, not the actual JUI Button component.
